通过浏览器插件安装，每次访问指定网页时会自动执行

安装浏览器插件

推荐选择暴力猴，因为篡改猴加载速度会更慢，可能会带来一些问题

暴力猴要开启同步 page 模式

下载地址：

篡改猴 (Chrome) 暴力猴 (Chrome) 篡改猴 (Firefox) 暴力猴 (Firefox) 篡改猴 (Edge) 暴力猴 (Edge)

需要给篡改猴或暴力猴开启允许用户脚本

安装用户脚本

在线安装

  1. 访问用户脚本列表
  2. 点击任意脚本，会询问是否安装

通过脚本链接安装

  1. 打开篡改猴或暴力猴的管理面板
  2. 篡改猴点通过url安装，暴力猴点通过地址安装
  3. 点击安装

离线安装

  1. 打开篡改猴或暴力猴的管理面板
  2. 把下载好的 js 文件拖进去，会询问是否安装
