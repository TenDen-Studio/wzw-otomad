# 吴梓文鬼畜资源库 (WZW-otomad)

这是吴梓文鬼畜的资源库，包含鬼畜展示与鬼畜制作相关页面。

## 目录结构

- `index.html` / `styles.css` / `load.js` / `list.json` — 站点首页与导航
- `鬼畜展示/` — 鬼畜视频、音频展示页及媒体文件（视频/音频走 Git LFS）
- `鬼畜制作/` — 鬼畜制作相关（含 Scratch `.sb3` 工程）
- `JavaScript/` — 站点脚本
- `Extension/` — 扩展页面
- `image/` — 图片资源
- `docs/` — 文档

## 说明

- 媒体文件（`.mp4` / `.wav` / `.mp3`）使用 Git LFS 托管，克隆前请先安装 [Git LFS](https://git-lfs.com/)。
